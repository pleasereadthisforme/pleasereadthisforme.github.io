    Before you start.
    Windows x64 Preview +
    The desktop app is available for Windows x64 only. No macOS, iOS or Android app is currently provided.
    Your OpenAI API key +
    Bring your own OpenAI API key. API charges are separate. Never enter your key on this site.
    Local storage. External model calls. +
    App data stays in local storage. Model calls may send questions, chat context, document content and paths to OpenAI. Preparation and embedding show costs before execution.
    You manage the app data. +
    Inspect and clean up storage in the app. Uninstalling does not delete app data.
